# Travel Hacks — чеклист путешественника

Интерактивная веб-страница в редакционном стиле: лайфхаки и чеклист для планирования отпуска без разочарований. Вдохновлено форматом travel-гайдов с интерактивными нумерованными пунктами.

## Возможности

- **Три категории**: планирование, спонтанные поездки, универсальные лайфхаки
- **Интерактивная сетка**: нажмите на номер — откроется полный совет
- **Чеклист с прогрессом**: отмечайте выполненные пункты
- **Два режима**: сетка (как в editorial-гайдах) и список
- **Редакционный дизайн**: тёплый фон, serif-заголовки, цитаты

## Запуск локально

```bash
npm install
npm run dev -- -p 3456
```

Откройте [http://localhost:3456](http://localhost:3456)

## Стек

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- shadcn/ui

## Структура

- `src/data/travel-hacks.ts` — контент чеклиста (24 пункта)
- `src/components/travel-hacks-page.tsx` — главная страница
- `src/components/interactive-checklist.tsx` — интерактивный чеклист
